# Lehrlinge: SMS-Erinnerungen / SMS-напоминания

Отдельный необязательный модуль: `source/lehrlinge_reminders.gs`.
Использует существующие `Submissions`, `sendZadarmaSms_()` и настройки Zadarma.
После добавления файла модуль **выключен**. Изменять основной SMS-сервис не требуется.

## Расписание и правила

**Активировано 16.09.2026:** `setupLehrlingeWeekTrial` успешно выполнена в GAS.
До 23.09.2026 — только тестовый номер; с 23.09.2026 — первый дневной номер и копия пользователю.
Переход выполняется существующим триггером по дате Europe/Vienna; возвращаться для переключения не нужно.

Настройки в GAS → Project Settings → Script Properties:

- `LEHRLINGE_REMINDERS_LIVE_FROM=2026-09-23` — начало рабочего режима (имеет приоритет над MODE).
- `LEHRLINGE_REMINDERS_COPY_PHONE=+4368181289405` — дополнительный получатель в рабочем режиме.
  Очистить/удалить это свойство, чтобы оставить только дневной номер.
- Для отмены перехода удалить LIVE_FROM, оставив MODE=test.
- Повторный запуск `setupLehrlingeWeekTrial` назначает переход через 7 дней от запуска.
  `setupLehrlingeReminderTest` отменяет автоматический переход и возвращает тестовый режим.

- Время: Europe/Vienna, включая летнее/зимнее время.
- Триггер каждые 5 минут; проверка в течение часов 09:00–09:59 и 17:00–17:59.
  Обычно первый запуск происходит в первые 5 минут, но Google не гарантирует точное время.
- Утром: сегодняшние Früh R1/R2. Вечером: сегодняшние Früh и Nachmittag R1/R2.
- В обоих случаях: **последние 3 рабочих дня** перед сегодняшним (полные дни, обе смены, оба маршрута).
  Выходные и праздники пропускаются, окно через них продолжается (в понедельник проверяются пятница, четверг, среда).
  Количество дней: Script Property `LEHRLINGE_REMINDERS_PREVIOUS_DAYS` (целое 0–10, по умолчанию 3; `1` = как раньше, но через выходные).
  Пока замечание не исправлено, оно повторяется в каждом сообщении, пока день не выйдет из окна.
- Суббота, воскресенье и 13 общегосударственных австрийских праздников исключены (сегодня в такой день сообщений нет).
  Источник: https://www.wien.gv.at/inhalt/feiertage
- Каникулы и местные исключения автоматически не определяются: **во время каникул окно из 3 дней даст ложные «fehlt»**,
  поэтому заранее вносите их в исключения. Дополнительные даты без поездок:
  Script Property `LEHRLINGE_REMINDERS_EXCLUDED_DATES`, например `2026-09-17,2026-09-18`.
- Проверяются отсутствие/дубли комбинаций дата–смена–маршрут, неверная смена/маршрут,
  пустая/неверная дата у отчёта, отправленного в проверяемый день.
- Nachmittag, отправленный до 12:00 в день поездки, помечается как возможная ошибка смены.
  По времени отправки нельзя достоверно установить фактическую смену. Поздний Früh допустим.
  Верность километража и фактически выполненный маршрут этот модуль не устанавливает.
- Исправления перечитываются непосредственно из таблицы. При дубле нужно исправить или удалить лишнюю строку.
  Пустой прошлый день внутри недели считается отсутствующими отчётами: удаление всех строк
  администратором невозможно отличить от отсутствия отправок.
- Если отклонений нет, SMS нет. Один сводный текст может тарифицироваться как несколько SMS-сегментов.

## Локальная проверка

`node --test tests/lehrlinge-reminders.test.mjs`

Тесты используют имитацию Google Apps Script и SMS; сеть и реальные SMS не вызываются.

## Проверка в Google Apps Script после согласования локальных изменений

1. Добавить содержимое `source/lehrlinge_reminders.gs` отдельным файлом `lehrlinge_reminders.gs`
   в тот же Apps Script, где находятся `Submissions` и основной SMS-сервис.
2. Запустить `previewLehrlingeMorning` и `previewLehrlingeAfternoon`.
   Они выводят текст, даты и получателя в журнал, **не отправляя SMS**.
3. Запустить `setupLehrlingeReminderTest`: устанавливает тестовый режим и единственный триггер этого модуля.
   Повторный запуск не создаёт дубли триггеров. Существующие триггеры Vorbestellungen не затрагиваются.
4. В 09 или 17 часов можно запустить `processLehrlingeReminders` вручную либо дождаться триггера.
   При отклонениях SMS отправится **только на +4368181289405**, с префиксом `[TEST]`.
   В тестовом режиме побочное SMS о низком балансе отключено.
5. После проверки для рабочего режима изменить Script Property `LEHRLINGE_REMINDERS_MODE` на `live`.
   Получатель — первый дневной номер `SMS_NOTIFICATION_PHONE_DAY` из существующих настроек.
   Отсутствующий дневной номер вызывает ошибку; подстановка ночного номера не выполняется.

## Каналы: WhatsApp-группа вместо SMS

Script Property **`LEHRLINGE_REMINDERS_CHANNELS`**: `sms,whatsapp` (по умолчанию, как раньше),
`whatsapp` (только WhatsApp) или `sms`. Неверное значение останавливает отправку с ошибкой.

- **Режим** задаёт получателя WhatsApp и префикс: `test` → ваш номер +43 681 81289405 и `[TEST]`;
  `live` → группа «Pöls Lehrlinge-wer fährt?» и текст без `[TEST]`.
- **Переключить сразу:** запустить в GAS **`setupLehrlingeWhatsAppLive`**. Функция включает `live`,
  убирает `LIVE_FROM`, ставит `CHANNELS=whatsapp`, оставляет один триггер и не запускается,
  если бот WhatsApp (`MINEEV_BOT_URL`/`MINEEV_BOT_TOKEN`) не настроен.
  Перед этим проверить текст: `previewLehrlingeMorning` / `previewLehrlingeAfternoon`
  (в ответе видны `mode`, `channels`, `whatsappTarget`, ничего не отправляется).
- **Вернуть SMS:** `restoreLehrlingeSmsChannel` (`CHANNELS=sms,whatsapp`).
  **Вернуться в тест:** `setupLehrlingeReminderTest` (режим `test`, `CHANNELS` остаётся, значит тест придёт в WhatsApp на ваш номер).
  **Выключить всё:** `disableLehrlingeReminders`.
- Без SMS-канала не нужен дневной номер и не тратятся SMS.
- **Повторы WhatsApp:** сообщение не считается отправленным, если бот вернул `skipped` (нет доступа) или ошибку HTTP.
  Такая подтверждённая неудача повторяется в тот же срок проверки (каждые 5 минут, не более 3 попыток).
  При неясном результате (таймаут, некорректный ответ) автоповтора нет, чтобы не задвоить сообщение в группе.
  Статус: Script Property `LEHRLINGE_REMINDERS_LAST_WA_09` / `_17` (`sent`, `failed`, `failed_or_unknown`, `attempts`).
- Автопереход по `LIVE_FROM` по-прежнему работает (при `CHANNELS` по умолчанию `live` включает SMS и WhatsApp в группу).

## Ручной тест в любое время

Дополнительный файл `source/lehrlinge_reminders_test.gs`: `previewLehrlingeTestNow`
показывает текст, `sendLehrlingeTestNow` отправляет его только на тестовый номер.
До 09:00 используется вечерняя проверка вчерашнего дня; с 09:00 — утренняя,
с 17:00 — вечерняя сегодняшнего дня. Расписание не включается.
При отсутствии отклонений отправляется явное тестовое подтверждение.
Повторная попытка для той же даты/смены блокируется свойством
`LEHRLINGE_REMINDERS_MANUAL_TEST_RFC1738`.

Проверка 16.09.2026 в 01:23 Europe/Vienna: Zadarma приняла 1 SMS за 0,03 EUR
с отклонениями за 15.09.2026. Доставка на телефон требует подтверждения получателя.
При проверке исправлен `formEncode_` в `source/code.gs`: символы `!'()*~`
кодируются по RFC1738, как требует подпись Zadarma. До исправления текст со скобками
получал HTTP 401; после исправления тот же текст получил HTTP 200 / success.
Исправление сохранено в редакторе GAS и локально; версия веб-деплоя после этого не обновлялась.

## Выключение

Запустить **`disableLehrlingeReminders`**: выключает модуль и удаляет только его триггеры.
Альтернатива: установить Script Property **`LEHRLINGE_REMINDERS_ENABLED=false`**.
Для возврата к тестированию: `setupLehrlingeReminderTest`.

## Диагностика отправки

`LEHRLINGE_REMINDERS_LAST_09_<номер>` и `LEHRLINGE_REMINDERS_LAST_17_<номер>` хранят дату, режим,
получателя и результат (`attempting`, `sent`, `failed_or_unknown`). Блокировка защищает от
одновременных запусков. Для одного получателя/режима не более одной попытки за каждый срок проверки.
Если результат отправки неизвестен или получена ошибка, автоматической повторной отправки
в тот же срок нет: проверьте Executions и историю Zadarma. Только после проверки доставки
можно удалить соответствующее свойство LAST для ручного повтора в тот же час.
При следующем сроке проверки актуальные отклонения проверяются снова.

Загрузка кода, установка триггера и реальные SMS не выполняются локальными тестами.
